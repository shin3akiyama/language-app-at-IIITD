# Language App at IIITD

インド留学中に、ディスレクシアのある児童に向けて作成した語学学習アプリです。

ディスレクシアは、知的発達や視力の問題とは別に、文字を読む・書くことなどの習得に困難が生じる学習特性です。このアプリでは、学習時間や成果を記録し、ランキングと継続日数を通じて、学習を続けるきっかけを提供します。

## 制作時期

2025年2月〜3月

## 技術スタック

- Frontend: React, Vite, Axios
- Backend: Node.js, Express, CORS
- Language: JavaScript

## 主な機能

- 学習時間の記録
- 学習カテゴリの追加
- 学習時間、成果、継続日数に応じたポイント計算
- ユーザーランキングの表示

## セットアップ

### 1. 依存関係をインストール

```bash
npm install
cd frontend
npm install
cd ..
```

### 2. バックエンドを起動

```bash
npm start
```

### 3. フロントエンドを別のターミナルで起動

```bash
cd frontend
npm run dev
```

ブラウザで表示されたViteのURL（通常は `http://localhost:5173`）を開いてください。

APIのURLを変更する場合は、`frontend/.env.local` に `VITE_API_URL` を設定します。設定例は `.env.example` を参照してください。

## 注意事項

このアプリは学習用のプロトタイプです。現在のデータはバックエンドのメモリ上に保持されるため、サーバーを再起動するとリセットされます。また、認証・永続データベース・本番環境向けのアクセス制御は実装していません。
